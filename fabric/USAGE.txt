NOTE: Server runs on http://localhost:3000

Data is submitted automatically by send_http.py running on the base node host.
The Python script reads JSON from the base node serial port, computes real
measurement timestamps (from device uptimes), and POSTs to this server.

HOW TO USE:

POST /visit
  Submit a sensor node visit to the blockchain.
  A visit is one mobile-node collection event: a node name and up to 12
  sensor readings, each with its own computed Brisbane datetime timestamp.

  The visit-level ledger key is derived from the first reading's sensor_meas_time.

  Body (JSON):
    {
      "name": "garden",
      "readings": [
        {
          "temp":             2310,
          "humidity":         55,
          "pressure":         101200,
          "moisture":         42,
          "sensor_meas_time": "2026-05-26 14:32:01.456 AEST"
        },
        {
          "temp":             2295,
          "humidity":         56,
          "pressure":         101198,
          "moisture":         41,
          "sensor_meas_time": "2026-05-26 14:32:03.456 AEST"
        }
      ]
    }

  Note: temp and pressure are scaled integers (divide by 100 for real values).
        e.g. temp 2310 = 23.10 C,  pressure 101200 = 1012.00 hPa
        sensor_meas_time is a Brisbane time string (AEST, UTC+10, no DST).

  Example:
    curl -X POST http://localhost:3000/visit \
      -H "Content-Type: application/json" \
      -d '{
        "name": "garden",
        "readings": [
          { "temp": 2310, "humidity": 55, "pressure": 101200, "moisture": 42, "sensor_meas_time": "2026-05-26 14:32:01.456 AEST" },
          { "temp": 2295, "humidity": 56, "pressure": 101198, "moisture": 41, "sensor_meas_time": "2026-05-26 14:32:03.456 AEST" }
        ]
      }'

  Response:
    { "success": true, "id": "garden_2026-05-26 14:32:01.456 AEST" }

________________________________________________________________________________________________________

GET /visits
  Returns all visits from the blockchain.

  Example:
    curl http://localhost:3000/visits

________________________________________________________________________________________________________

GET /visits/:nodeName
  Returns all visits for a specific sensor node.

  Example:
    curl http://localhost:3000/visits/garden

________________________________________________________________________________________________________

GET /visit/:id
  Returns a single visit by its full ID ("<name>_<sensor_meas_time of first reading>").

  Example:
    curl "http://localhost:3000/visit/garden_2026-05-26%2014%3A32%3A01.456%20AEST"
