NOTE: Server runs on http://localhost:3000

HOW TO USE:

POST /visit
  Submit a sensor node visit to the blockchain.
  A visit is one mobile-node collection event: a node name, a timestamp,
  and up to 12 sensor readings taken during that visit.

  Body (JSON):
    {
      "nodeName":  "garden",
      "timestamp": "2026-05-21T08:32:00",
      "readings": [
        { "Temp": 2310, "Humidity": 55, "Moisture": 42, "Pressure": 101200, "MeasTime": 1500 },
        { "Temp": 2295, "Humidity": 56, "Moisture": 41, "Pressure": 101198, "MeasTime": 3000 }
      ]
    }

  Note: Temp and Pressure are scaled integers (divide by 100 for real values).
        e.g. Temp 2310 = 23.10 °C,  Pressure 101200 = 1012.00 hPa

  Example:
    curl -X POST http://localhost:3000/visit \
      -H "Content-Type: application/json" \
      -d '{
        "nodeName":  "garden",
        "timestamp": "2026-05-21T08:32:00",
        "readings": [
          { "Temp": 2310, "Humidity": 55, "Moisture": 42, "Pressure": 101200, "MeasTime": 1500 },
          { "Temp": 2295, "Humidity": 56, "Moisture": 41, "Pressure": 101198, "MeasTime": 3000 }
        ]
      }'

  Response:
    { "success": true, "id": "garden_2026-05-21T08:32:00" }

________________________________________________________________________________________________________

GET /visits
  Returns all visits from the blockchain.

  Example:
    curl http://localhost:3000/visits

________________________________________________________________________________________________________

GET /visits/:nodeName
  Returns all visits for a specific sensor node.

  Example:
    curl http://localhost:3000/visits/garden

________________________________________________________________________________________________________

GET /visit/:id
  Returns a single visit by its full ID ("<nodeName>_<timestamp>").

  Example:
    curl http://localhost:3000/visit/garden_2026-05-21T08:32:00
